⚡ REST API Endpoints for Frontend UI

Use these REST API endpoints in React, Vue, Angular, or Vanilla JS to control the camera. Full CORS is enabled.

1. Continuous Move (On Button Down / Hold)
// POST /api/ptz/move fetch("http://localhost:8085/api/ptz/move", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ direction: "left", speed: 0.5 }) // up, down, left, right, etc. });
2. Stop Movement (On Button Release / Mouseup)
// POST /api/ptz/stop fetch("http://localhost:8085/api/ptz/stop", { method: "POST" });
3. Step Nudge (On Single Click)
// POST /api/ptz/step fetch("http://localhost:8085/api/ptz/step", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ direction: "up", speed: 0.5, duration: 0.35 }) });
4. Zoom In / Out
// POST /api/ptz/zoom fetch("http://localhost:8085/api/ptz/zoom", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ direction: "in", speed: 0.5 }) // "in" or "out" });
